# 足迹地图的相邻城市选择

地图圆点保持真实坐标。厦门和金门的圆点在全国地图上几乎重合，不能要求用户精确点击两点之间的一两个像素。

选中地点后，按当前显示尺寸查找相距小于 24 CSS px 的圆点分组；如有多个城市，在影集预览上方显示“选择城市”按钮。每个按钮至少 44px 高，选中态深墨青，支持鼠标、触屏、键盘与既有快门回弹。窗口缩放时重算分组，保留所选城市；选择区隐藏时将其中的焦点归还地图按钮。孤立城市保持直接显示影集的行为。

1000px 及以下视口将预览与城市选择区放在地图下方，避免鼠标悬停弹出卡片后遮住原圆点、后续点击误进入影集。更宽屏幕保持右下角预览。Escape、关闭按钮和地图外点击均可关闭；影集链接仍使用正常网页导航。

浏览器验收使用真实 CDP 鼠标和触屏事件：刻意点在厦门/金门重叠区域偏外的位置，再分别点击大按钮；覆盖 320、390、768、1440px、键盘 Enter/Escape、关闭/外部点击、窗口缩放与焦点恢复。不只用 element.click() 验证重叠圆点。

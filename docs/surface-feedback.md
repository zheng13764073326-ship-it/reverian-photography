# 封面反光与按钮反馈

参考用户指定的 [chuweimin.com](https://chuweimin.com/) 中封面斜向反光、跟随高光与轻微倾斜的交互方式，按本站浅色纸张、暖金色及现有摄影取景光标设计实现。没有更换封面照片、内容、布局或字体。

入口为 `HoverFeedback.astro`，调用 `lib/surface-feedback.ts` 并加载 `styles/surface-feedback.css`。

- 首页、影集列表及影集末尾“下一本影集”的照片面添加两层无交互装饰：1.1 秒斜向扫光与鼠标位置决定的柔和高光。只倾斜照片面，标题等文字保持原布局。
- 使用未变形的 figure 测量鼠标位置，避免倾斜改变输入坐标。每次鼠标移动最多安排一个动画帧；空闲时没有持续的循环。移出、滚动、失焦、离开页面或切换系统减少动态效果设置时复位。
- 反光只在精确鼠标、可悬停且允许动态效果时启用。原有封面曝光闪亮与边缘滤镜不再叠加；其他单张照片保留其原有反馈。
- 按钮和主要操作链接使用既有按压机制，松开后的弹性过渡调整为 420ms；小圆按钮缩至 92%，主要操作按钮缩至 96.5%。符合条件的按钮从按下位置发出 520ms 的轻微暖色亮光，范围限制在按钮内部。
- 亮光使用临时子元素与 Web Animations，不修改按钮正文、默认操作、事件传播或导航时机。鼠标、触摸、键盘 Enter/Space 均可触发；动态添加的选项通过事件委托接入。动画结束或被打断后清理节点和临时定位属性。
- 地图点位、图片预览按钮、上传区排除亮光；地图点位原有定位变换保留。禁用、隐藏、inert 控件不触发亮光；拖动超过 8px、滚动、pointercancel、失焦和页面隐藏会取消。
- 手机不启用封面倾斜，保留按压反馈；减少动态效果时禁用扫光、倾斜、亮光和动态按压。

验证涵盖首页、影集列表、关联影集，鼠标位置变化、离开与滚动复位、封面链接导航、按钮按住与回弹、键盘、连续点击清理、地图缩放和点位、禁用按钮、触摸滚动和系统减少动态效果。照片大图另行回归检查切换、手记与滑动。

# 照片浏览与切换

全站共用 `Lightbox.astro`。普通照片、影集、作品页与胶片来信使用相同的切换逻辑。

- 打开时沿用相纸浮起与白边；带手记的照片直接打开后翻至背面，普通照片保持正面。从正面切换到手记照片也保持正面。
- 打开浏览器后预加载前后各一张大图，并通过 `decode()` 提前完成解码。`DecodedPhotos` 最多保留六张图片，关闭时释放引用，尚未完成的预加载会取消。
- 未缓存的照片同时准备可用预览图与大图。至少一张解码成功才替换当前照片；预览先准备好时先显示预览，大图解码后原位升级。等待期间保留当前照片，450 ms 后显示载入状态。
- 切换时保留旧画面的临时副本，280 ms 淡出并向切换反方向移动 24 px；新照片从切换方向移动 28 px、淡入，340 ms 完成。临时副本无重复 ID、不参与焦点或辅助阅读，动画结束或被打断时移除。
- 左右按钮、方向键与触摸滑动共用同一路径；连续输入累计目标位置，只允许最新请求提交。关闭、重新打开及手动翻面会作废先前的切换请求，迟到的大图不会覆盖新选择。
- 解码失败保留当前画面并显示可重试提示。系统设置减少动态效果时直接切换，不执行位移或淡入淡出。

验证包括缓存去重、优先级、淘汰、失败重试、关闭后迟到响应，以及浏览器中的方向动画、快速切换、慢解码、失败、关闭重开、手记翻转、手机滑动和减少动态效果。

# 阶段进度

## 第一阶段：本地基础版本

已实现 Astro/TS 工作区、Sanity schema 与 Studio 配置、演示数据、发布数据接口、Pages 构建配置和 GitHub 检查工作流。现有视觉素材保留。云端 Sanity/Cloudflare 项目按用户意愿暂缓创建。

为了让基础可以直接浏览，提供全站页面初版和示例内容，而不是只有空项目。

验证已通过：Astro 与 Studio 类型检查（0 错误、0 警告）、15 页静态构建、五类文档离线 schema 提取、内容公开状态与 500 张照片分页测试。1440×1000、834×1112、390×844 三种尺寸浏览器检查通过，包含大图打开、前后切换、Esc、菜单与触摸滑动；327 个本地资源及导航引用有效。浏览器报告与截图保存在 `artifacts/`。这些检查不代替真实 Sanity、Webhook 与 Cloudflare 的联调。

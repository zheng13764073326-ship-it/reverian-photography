# 首页封面

首页采用林荫道路实拍照片和独立网页文字，电脑与手机分别排版，参考用户提供的横、竖版设计。没有 “Kinmen Notes” 副标题。

- 背景复用 `kinmen-2026-14` 的现有压缩 JPEG：`image-b9cd28b14e696b661f0d0e5389f216319216c45a-4096x2678-jpg`。不上传 `E:/上海/1/14.png` 原始大文件，不更改金门影集照片。
- `siteSettings.homePresentation` 为 `photograph`；`homeCover` 和 `mobileCover` 均引用该照片。桌面焦点 `(0.5, 0.05)`，手机焦点 `(0.39, 0.5)`。
- 桌面保留横向画面，居中斜体标题，上方导航无长横线，底部只有缓慢明暗变化的向下箭头。编号、分类、Scroll 和 Explore 文案已移除。
- 用户进一步要求手机保留参考图中的完整道路，因此手机改用独立竖版背景。使用内置 image_gen 编辑用户的竖版参考，移除网页文字和 UI，压缩原图作为实拍细节参考；完整保留参考图中的左右路边、石碑和黄色中线。编辑提示词保存在 `home-cover-mobile-prompt.txt`。
- 800px 以下的竖屏按整幅图片宽度显示，图片保持比例并与封面底部对齐，不使用横向填充裁切。高屏上方用同一素材的树冠填满额外空间。标题、导航和向下箭头均为真实网页元素。箭头保留 52px 点击区域和无障碍名称，点击进入精选作品；开启减少动态效果时静止显示。
- 手机 JPEG 继续使用已确认的原生 941×1671 竖图，从原 PNG 导出 v3 高质量版本，不放大像素、不采用有细节失真的生成式增强版本。宽度为 400、800、941px，体积分别约 172、554、1069 KB，存放在 `apps/web/public/images/covers/`。树冠按屏幕宽度和像素密度通过 CSS image-set 选择素材，高密度手机不再固定使用 400px 小图；树冠和完整竖图可以复用同一个资源。背景素材仅用于首页设计，不加入实拍影集。
- 桌面继续使用原压缩照片，首页专用响应式尺寸扩展至原生 4096px，不影响其他页面。生产构建通过 `localize-images.mjs` 生成同站静态图片。手机加载失败时也重试竖版小图，保持完整道路。
- 导航文字、标题及浏览提示均为 HTML，不写进照片。斜体使用本地 Cormorant Garamond 字体。
- 首页导航品牌显示 Reverian，其他页面保留原导航标识；原有导航菜单、光圈入场、滚动入口与减少动态效果支持继续保留。

主要文件：`HomeCover.astro`、`Header.astro`、`Base.astro`、`global.css`。修改前后的 CMS 快照、浏览器检查和预览保存在忽略提交的 `artifacts/home-cover-redesign/`。
